# FINAL_NOVELTY_POSITIONING

The paper's contribution is a **joint evaluation architecture**, not any single new component. Classification of each candidate claim:

| Claim | Class | Wording guidance |
|---|---|---|
| Strong recent-surveillance comparator + matched climate-block ablation + calibration + proper scoring + decision-curve net benefit + development-inclusive uncertainty, used to ask *what incremental value does climate add beyond recent surveillance?* | **`SUPPORTED_AS_INTEGRATION`** | This is the strongest, defensible identity. State as an integration/architecture contribution. |
| No prior population-level dengue early-warning study evaluated forecasts by decision-curve net benefit (vs individual clinical prognosis) | **`NEEDS_HEDGE`** → applied | Use "to our knowledge, we did not identify a prior…"; not "first-ever" (Scopus/WoS not searched). See `DCA_DENGUE_NOVELTY_VERIFICATION.md`. |
| Matched ablation isolates the climate feature block; M4−M1 (non-nested) does not | **`SUPPORTED`** | Backed by S9 feature counts; `MATCHED_COMPARATOR_STRUCTURE.md`. |
| Development-inclusive (refit-both) vs conditional uncertainty distinction applied to a climate ablation | **`SUPPORTED`** | Methodological emphasis, not "first bootstrap." |
| Metric-oriented incremental value $\Delta V_{C,k}$ separating ranking / probability accuracy / decision value | **`SUPPORTED_AS_INTEGRATION`** | Framing/precision contribution ("we make explicit"). |
| Climate adds no value / is unimportant to transmission | **`REMOVE`** | Finding is "no robust evidence of operationally meaningful increment," not a proven null. |
| First DCA / first climate dengue forecast / first surveillance comparison / first spatial-representativeness demonstration | **`REMOVE`** | Untrue and/or unsupported. |
| Validated, transportable, deployment-ready; formal SL–CO heterogeneity | **`REMOVE`** | Explicitly disclaimed; no such test performed. |

**Bottom line:** lead with the integration architecture and the deflationary finding; keep exactly one hedged DCA sentence; avoid every "first-ever." The paper stands even if the climate increment is null.
