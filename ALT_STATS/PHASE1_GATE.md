## Gate decisions (per Section-0 / Section-4 rules)
- **Route A (frozen-prediction proper scoring): PROCEED.** Both settings' frozen model
  predictions are REPRODUCED. The matched no-climate arm is regenerated by the
  reproduce-gated deterministic V6 pipeline and **frozen into `ALT_STATS/frozen/`** with a
  built-in fidelity cross-check (regenerated M5 vs committed frozen M5). This provenance is
  documented in `FROZEN_INPUTS_MANIFEST.md` and `deviations.md`; the analysis does not edit
  any V6 artifact.
- **Development-inclusive proper-score intervals: DO NOT COMPUTE.** The refit-both-models
  bootstrap was not re-executed this session. Report conditional frozen-prediction
  intervals only, and state this explicitly in every Phase 2 report.
